# 🧑‍💻 Coding Arena — Nơi viết code khi làm bài coding

> Khi chạy mock interview **type `coding`** (hoặc câu coding trong `comprehensive`), interviewer ra đề và bạn **viết code trực tiếp vào thư mục này** (mỗi bài một file). Interviewer đọc file ở đây để **review**: đúng/chạy, độ phức tạp, edge case, style, bản mẫu.

## Quy ước
- Mỗi bài một file, đặt tên gợi ý interviewer đưa: vd `reverse_list.cpp`, `ring_buffer.cpp`, `two_sum.py`.
- Ngôn ngữ tùy đề (C/C++ mặc định cho track embedded/system).
- Cứ để nháp, chạy thử, sửa thoải mái — đây là "giấy nháp".

## ⚠️ Thư mục này bị **git-ignore**
Mọi file bạn viết ở đây **không được commit** (chỉ có `README.md` này được track) — xem [.gitignore](../../../.gitignore) ở gốc repo. Code luyện tập là nháp cá nhân, không làm bẩn lịch sử repo. Nếu muốn giữ một lời giải hay, chép ý tưởng vào [../bank/coding.md](../bank/coding.md) dưới dạng bản mẫu.
